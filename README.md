# SQL Data Analysis: SampleSuperstore
A comprehensive business intelligence project executing 25+ SQL queries to extract actionable insights from retail sales and customer datasets.

### 🛠️ SQL Skills Demonstrated
* **Data Filtering & Aggregations:** `WHERE`, `LIKE`, `BETWEEN`, `GROUP BY`, `HAVING`
* **Advanced Joins:** Combining customer and transactional data using `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN`
* **Analytical Techniques:** Complex subqueries, performance ranking (`LIMIT`), and margin tracking
